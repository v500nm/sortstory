# Learn & Practice Module - Project Plan

## Overview
This document manages the implementation of the "Learn and Practice" module. This module provides a structured, deep-dive curriculum for all algorithms in SortStory (Sorting, Pathfinding, Linked Lists, Trees, Graphs, Automata).

## Objectives
- Create a `/learn` curriculum.
- Support language toggling (Python, JS, Java, C, C++) for code explanations.
- Organize lessons into: Introduction, Implementation, and Practice Problems.
- Build a resilient Markdown rendering system using `react-markdown`.

## Milestones
- [ ] Setup Markdown dependencies and file structures.
- [ ] Create UI for `/learn` (Sidebar for navigation, main content area for lessons).
- [ ] Implement custom Markdown renderer for dynamic language toggling.
- [ ] Populate content for Sorting Algorithms.
- [ ] Populate content for Pathfinding Algorithms.
- [ ] Populate content for Linked Lists.
- [ ] Populate content for Graphs.
- [ ] Populate content for Trees.
