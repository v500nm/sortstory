## Engineering Approach

**Deterministic Execution** — Algorithms run predictably in WASM or native JS contexts.
**Zero-Lag Rendering** — Built on heavily optimized React state and Canvas to handle 10k+ nodes.
**Visual First** — Abstract concepts are transformed into visceral, visual interactions.

## Stack

```
Web        →  Next.js, React, Tailwind CSS, TypeScript
Backend    →  Supabase, Edge Functions
Animations →  Framer Motion, Canvas API
Deployment →  Vercel, GitHub Actions
```
